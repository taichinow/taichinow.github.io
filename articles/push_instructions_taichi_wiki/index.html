How to push #

Option A: PowerShell (recommended on Windows) #

powershell 
# In the VI repo
cd C:\Users\Henry\Documents\taichi-wiki
.\push-to-github.ps1
# When prompted, paste your GitHub token (ghp_...)

# In the EN repo
cd C:\Users\Henry\Documents\taichi-wiki-en
.\push-to-github.ps1
# When prompted, paste your GitHub token (ghp_...)

Option B: git-bash / WSL #

bash 
# In the VI repo
cd /c/Users/Henry/Documents/taichi-wiki
bash push-to-github.sh
# When prompted, paste your GitHub token (ghp_...)

# In the EN repo
cd /c/Users/Henry/Documents/taichi-wiki-en
bash push-to-github.sh
# When prompted, paste your GitHub token (ghp_...)

The script will:

  1. Create the GitHub repos (HenryPhamDuc/taichi-wiki and HenryPhamDuc/taichi-wiki-en)
  2. Enable GitHub Pages (source: GitHub Actions)
  3. Push to main
  4. Wait for the first deploy to complete (≈2-3 minutes)
  5. Print the live URL

Option C: Pre-set your token #

If you have your token in GITHUB_TOKEN env var, the scripts will use it without prompting.

What the user will see #

After the first push, the workflow will:

  • Build with mkdocs build --strict (takes ~30s for 148 articles)
  • Deploy to gh-pages via actions/deploy-pages@v4
  • Sites live within ~2-3 minutes of the push

Questions #

If push fails, check:

  1. Your token has repo and workflow scopes
  2. The repos don't already exist (the script is idempotent)
  3. GitHub Pages is enabled (script does this automatically)

If the build fails, check the GitHub Actions log at:

  • https://github.com/HenryPhamDuc/taichi-wiki/actions
  • https://github.com/HenryPhamDuc/taichi-wiki-en/actions
