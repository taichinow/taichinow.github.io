🌿 Taichi Wiki — Portable Bundle #

This bundle contains two ready-to-push MkDocs wiki sites:

Folder GitHub repo Live URL (after push)
taichi-wiki/ HenryPhamDuc/taichi-wiki https://henryPhamDuc.github.io/taichi-wiki/
taichi-wiki-en/ HenryPhamDuc/taichi-wiki-en https://henryPhamDuc.github.io/taichi-wiki-en/

Both contain:

  • 148 articles each (VI and EN) across 8 sections
  • Material for MkDocs static site
  • D3.js v7 interactive knowledge graph
  • GitHub Actions auto-deploy workflow
  • Cross-links to Henry's Taichi Practice Vault and the Tennis Wiki ecosystem

How to push from a different machine #

Option 1: PowerShell (Windows) #

powershell 
# In the VI repo
cd C:\path\to\taichi-wiki
.\push-to-github.ps1
# When prompted, paste your GitHub token (ghp_...)

# In the EN repo
cd C:\path\to\taichi-wiki-en
.\push-to-github.ps1

Option 2: git-bash / WSL / Linux / Mac #

bash 
cd /path/to/taichi-wiki
bash push-to-github.sh
# When prompted, paste your GitHub token (ghp_...)

What's needed #

  1. Git (any version 2.x+)
  2. GitHub Personal Access Token with scopes repo + workflow:
  • Generate at https://github.com/settings/tokens/new
  • Note: anything (e.g. taichi-wiki-deploy)
  • Expiration: 90 days or No expiration
  • Scopes: ✅ repo, ✅ workflow
  1. Python 3 only needed if you want to rebuild locally (not required for pushing)

What the script does #

  1. Creates the GitHub repo (idempotent — won't fail if it exists)
  2. Enables GitHub Pages with source = GitHub Actions
  3. Pushes to main
  4. Waits ~30s, then polls Actions for the first deploy
  5. Prints the live URL when deploy succeeds (~2-3 min total)

Local preview (optional) #

If you want to see the site before pushing:

bash 
# Requires: pip install mkdocs mkdocs-material pymdown-extensions pygments
cd taichi-wiki
mkdocs serve
# Open http://127.0.0.1:8000

If push fails #

  • HTTP 401 on repo create: Token is invalid. Regenerate at https://github.com/settings/tokens/new
  • Build fails: Check Actions log at https://github.com/HenryPhamDuc/taichi-wiki/actions or taichi-wiki-en/actions
  • "Token too short": The Read-Host prompt may have eaten your paste. Try generating a new token, copying the FULL ghp_... string, and pasting again.
  • "remote origin already exists": Run git remote remove origin then re-run the script
