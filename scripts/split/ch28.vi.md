3-Mỏ Neo Kiểm Tra, 3-Câu Hỏi Chẩn Đoán, Câu Nhắc Một-Từ

| 🇻🇳 Tiếng Việt |
|-------------|----------------|
| **Ý tưởng cốt lõi**: Chương này là *bảng tóm tắt* bạn giữ trong túi (hoặc dán trên gương phòng tắm). Toàn bộ cẩm nang, nén thành 3 hệ thống bạn có thể dùng hằng ngày. |
| **3-Mỏ Neo Kiểm Tra** — trước mỗi tập: |
| **Mỏ neo 1 — Chân**: Cảm 4 điểm. Gò ngón cái, gò ngón út, gót trong, gót ngoài. |
| **Mỏ neo 2 — Hơi thở**: Một thở bụng. Hít phình, thở co. |
| **Mỏ neo 3 — Đỉnh đầu**: Tưởng tượng sợi dây kéo lên. Kéo dài. |
| **3-Câu Hỏi Chẩn Đoán** — khi cái gì đó cảm thấy sai: |
| **C1: Tôi có trong Phòng không?**: Kiểm tra: tôi "đầy và mềm" hay "rỗng và mềm oặt" hay "khóa và cứng"? |
| **C2: Tôi có trong Hư/Thực không?**: Kiểm tra: một chân đầy, một chân rỗng? Một tay hoạt động, một tay nghỉ? |
| **C3: Tôi có đang thở không?**: Kiểm tra: hơi thở ở bụng hay ở ngực? Tôi có nín thở không? |
| **8 Câu Nhắc Một-Từ** — từ vựng hằng ngày: |
| 1. **Sōng** — Thả những gì không cần. |
| 2. **Hư** — Rỗng, sẵn sàng nhận. |
| 3. **Thực** — Đầy, sẵn sàng biểu đạt. |
| 4. **Phòng** — Khối cầu sẵn sàng có tổ chức. |
| 5. **Lãy** — Nhường, lắng nghe, chuyển hướng. |
| 6. **Án** — Gieo hạt. |
| 7. **Ý** — Ý dẫn dắt thân. |
| 8. **Hưu** — Nghỉ trong tĩnh lặng. |
| **Phiên bản "dán gương"**: In trang này. Dán lên gương phòng tắm. Đọc mỗi sáng. Toàn bộ bảng 3 hệ thống mất 30 giây để xem lại. |
